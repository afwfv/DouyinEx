## 2. 本轮改动（界面与抖音原生合作）

1. **速度跟原生一致**：`travelSeconds = duration / 1000`（原生默认 14400ms → 14.4s/屏）。此前 `12 × duration / 14400` 让所有档位都比原生快 20%，正是「偏快又改不了」的来源。
2. **面板「跟随抖音原生」摘要**：`字号 20 · 区域 60% · 速度 14.4s`，改原生弹幕设置即时刷新，用户不用猜插件有没有生效。
3. **面板限高可滚动**：`max-height: calc(100vh - 24px); overflow-y:auto; overscroll-behavior:contain`，小窗/笔记本不再把面板底部按钮顶出视口；宽度 296→312px，滚动条不再挤窄关键词编辑框（回归断言 `Keyword editor is too cramped`）。
4. **`Esc` 收起面板**：与「Esc 释放悬停选中」共存（capture 阶段关闭面板，原逻辑继续释放选中）。
5. **悬停暂停可关**：新增「悬停暂停单条弹幕」，默认开（等价旧行为）。关掉后 `hoverPause:false` 直接不建立暂停，指针扫过画面不再让轨道停顿。

## 4. 明确未做（保留给后续）

| 需求 | 原因 |
| --- | --- |
| 聊天列表暂停滚动 / Ctrl+F 定位 | 抖音聊天是虚拟列表（容器撑高 ~12834px，DOM 只留 13~20 行），要拦截滚动与搜索定位需接管 React 列表，风险大于收益 |

| 真机全链路复核 | 本次只在无头环境验证；插件挂载依赖真实播放状态（见 `danmaku-jitter.md` §6） |
